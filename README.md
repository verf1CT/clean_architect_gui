A beautiful, visual Desktop application for scaffolding Flutter projects using **Clean Architecture**. Say goodbye to manual folder creation and boilerplate code. 

## ✨ Features
* **Visual Interface:** Easy-to-use GUI built with Flutter Desktop.
* **Instant Scaffolding:** Generates `domain`, `data`, and `presentation` layers in seconds.
* **State Management Support:** Pre-configures BLoC, Riverpod, or Provider based on your choice.
* **Cross-Platform:** Available for macOS, Windows, and Linux.

## 🚀 Installation (macOS)
The easiest way to install on macOS is via Homebrew:
```bash
brew install verf1ct/tap/clean-architect-gui
```

## 📥 Manual Download
You can download the latest pre-compiled binaries for **macOS**, **Windows**, and **Linux** from our [Releases Page](https://github.com/verf1CT/clean_architect_gui/releases/latest).

## 🛠️ Usage
1. Open the application.
2. Enter your project name and target directory.
3. Select your preferred State Management solution.
4. Click **Generate Architecture** and watch the magic happen!
